== Steps

=== Step 1 – Submission to the Blue Gateway

The Blue Connector submits the business message to the Blue Gateway.
If the submission succeeds, a *SubmissionAcceptance* evidence is generated and sent with the business message to the Red Gateway.
If it fails, a *SubmissionRejection* evidence is sent back to the Blue MS National System and the flow ends.

=== Step 2 – Relay to the Red Gateway

When the message arrives and is accepted at the Red Gateway, the Red Connector sends a *RelayREMMDAcceptance* evidence back to the Blue Gateway/Connector, and optionally to the Blue Member State.
If the message reaches the Red Gateway but is not accepted, the Red Connector generates a *RelayREMMDRejection*, which is relayed back to the original sender.
If no acceptance is received before timeout and retries are impossible or exhausted, the Blue Connector generates a *RelayREMMDFailure* and sends it to the Blue MS National System.

=== Step 3 – Delivery to the Red MS National System

After acceptance, the message is forwarded to the Red MS National System.
When this system sends back a delivery receipt, the Red Connector generates a *DeliveryNonDeliveryToRecipient* with `eventCode = Delivery`, relayed to the original sender.
If the message cannot be delivered before timeout, a *DeliveryNonDeliveryToRecipient* with `eventCode = DeliveryExpiration` is sent back to the sender.

=== Step 4 – Retrieval by the recipient (optional)

This step only applies if retrieval evidence is used in the receiving country, i.e. if the Red MS National System provides retrieval information to the Red Gateway.
If the message is retrieved, the Red Gateway generates a *RetrievalNonRetrievalByRecipient* with `eventCode = Retrieval`.
If it is not retrieved before timeout, it generates a *RetrievalNonRetrievalByRecipient* with `eventCode = NonRetrievalExpiration`.
Both are relayed to the original sender.

NOTE: If retrieval evidence is not used in the receiving country, no retrieval or non-retrieval expiration evidence is generated or relayed: there is no proof of retrieval.
