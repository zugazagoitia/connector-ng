= e-CODEX Connector Configuration

All settings described in this guide are Spring Boot properties, read from `config/application.properties` (or from environment variables using Spring Boot's relaxed binding).
A complete, commented sample is shipped in the distribution package and in the container image.

In the property tables, *Optional* = _Yes_ means the property has a built-in default (shown in the *Example* column as "By default, ...") or is not needed for a minimal setup.
