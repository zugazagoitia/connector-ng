= Gateway JMS Broker Configuration

By default, the Domibus gateway embeds an Apache ActiveMQ broker for JMS messaging.
With connector 7.x, the gateway and the connector share an *external* ActiveMQ Classic broker instead.
Consequently, the gateway must be configured with the connection parameters of the external broker (URL, credentials and related JMS settings).

NOTE: This chapter describes properties of the *gateway* (Domibus), not of the connector.
They are set in the gateway's `domibus.properties` file (for a multitenant gateway, in the domain-specific properties file), not in the connector's `application.properties`.
The connector side is configured with `+spring.activemq.*+` (see the platform configuration chapter).
An example is available in the source repository under `docker/gateway/config/conf/domibus/domibus.properties`.

== Basic configuration
Configuration is provided via the gateway's `domibus.properties` under the `+activeMQ.*+` prefix.

.Gateway JMS Broker Configuration Properties
[cols="35,40,10,15", options="header"]
|===
| Property | Description | Optional | Example

| `activeMQ.broker.host`
| Host name (or container/service name) of the external ActiveMQ broker. Host name only, without a scheme: it is used to build the `tcp://` and JMX URLs below.
| No
| `activemq.example.org`

| `activeMQ.brokerName`
| Logical name of the JMS broker. Multiple comma-separated names can be defined for a broker network; the count must match the number of JMX service URLs in `activeMQ.JMXURL`. ActiveMQ recommends broker names be unique across the network.
| No
| `activemq-domibus`

| `activeMQ.embedded.configurationFile`
| Path to the embedded ActiveMQ broker's configuration file (XML). Only used when running an *embedded* broker; leave it empty when connecting to an *external* broker.
| Yes
| By default, set to `file:///${domibus.config.location}/internal/activemq.xml`

| `activeMQ.JMXURL`
| Service URL(s) for the JMX MBeanServer(s) exposed by the broker, used for monitoring/management. Built from the broker host and JMX connector port; one or more comma-separated URLs, count must match `activeMQ.brokerName`.
| No
| `service:jmx:rmi:///jndi/rmi://${activeMQ.broker.host}:${activeMQ.connectorPort}/jmxrmi`

| `activeMQ.connectorPort`
| Port the JMX connector listens on for management connections to the broker.
| No
| By default, set to `1099`

| `activeMQ.transportConnector.uri`
| Connection URI clients use to connect to the broker over TCP for actual message traffic (as opposed to the JMX management port above).
| No
| `tcp://${activeMQ.broker.host}:61616`

| `activeMQ.username`
| Username used to authenticate to the ActiveMQ broker.
| No
| `*secret*`

| `activeMQ.password`
| Password for the broker username above.
| No
| `*secret*`

| `activeMQ.persistent`
| Whether message persistence is enabled on the broker (messages survive broker restarts). Disabling improves throughput but risks message loss on restart/crash.
| No
| By default, set to `true`

|===

.Configuration Example
[source,properties]
----
#The host of the JMS broker
activeMQ.broker.host=activemq

#The name of the JMS broker; one or more names can be defined, comma-separated (must match the number of JMX service URLs,
#as defined in activeMQ.JMXURL)
#ActiveMQ recommends that the broker name must be unique in the network
activeMQ.brokerName=activemq-domibus

#The configuration file of the embedded ActiveMQ broker. In case an external broker is used, this property is not needed, and it should be removed
#activeMQ.embedded.configurationFile=file:///${domibus.config.location}/internal/activemq.xml
activeMQ.embedded.configurationFile=

#The service URL of the MBeanServers; one or more URLs can be defined, comma-separated (must match the number of broker names,
#as defined in activeMQ.brokerName)
activeMQ.JMXURL=service:jmx:rmi:///jndi/rmi://${activeMQ.broker.host}:${activeMQ.connectorPort}/jmxrmi

#The port that the JMX connector will use for connecting to ActiveMQ
activeMQ.connectorPort=1099

#The connection URI that the clients can use to connect to an ActiveMQ broker using a TCP socket
activeMQ.transportConnector.uri=tcp://${activeMQ.broker.host}:61616

#The username that is allowed to connect to the ActiveMQ broker
activeMQ.username=<broker_user>

#The password of the username defined in the activeMQ.username property
activeMQ.password=<broker_password>

#The persistence enabled flag
activeMQ.persistent=true
----
