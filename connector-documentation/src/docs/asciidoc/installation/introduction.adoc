= Introduction

== Scope and objective of this document
This document is a technical guide to install and configure the e-CODEX **Connector** (version {project-version}).
It is written as a step-by-step installation guide: readers should be able to install and configure the **Connector** in their own environment without prior knowledge of the software.

A detailed knowledge of your own environment (network, database, certificates) is a precondition.

The chapters are ordered so that they can be followed from top to bottom: the preconditions of each chapter are covered by the previous chapters.

As an installation guide, this document does not describe the features or the day-to-day usage of the **Connector**.
Configuration properties are described in the configuration guide, and changes between versions in the changelog.

== e-CODEX building blocks

The **Connector** is one of the building blocks that provide the connectivity and functionality of e-CODEX.
To exchange messages with other e-CODEX partners, the other building blocks (in particular the e-CODEX gateway, based on Domibus) must also be installed and configured.

A description of the e-CODEX building blocks and additional information on the e-CODEX system can be found on the link:https://www.ecodex.eu/tech[e-CODEX website].

== Product distribution

The **Connector** is distributed as a standalone application with an embedded *Tomcat* web server.
It can be deployed in two ways:

* <<docker-install,Containerized (Docker)>> – **recommended.** The container image can run on any OCI-compatible hosting platform.
* <<jar-install,Native (executable JAR)>> – for restricted environments where containers are not an option. The runnable JAR is executed directly on the host with Java 21.

Both options use the same configuration file (`config/application.properties`) and the same external services described in <<prerequisites>>.
