== Finding codes of the report

Every finding in `+migration-report.md+` and `+migration-report.json+` has a severity and a code.

* *INFO:* data was transformed in a documented way; nothing was lost.
* *WARNING:* review needed (placeholder, truncation, assumption).
* *ERROR:* a record or a payload could not be migrated as it was. The run continues, and its outcome is `+COMPLETED_WITH_ERRORS+` (exit code 2).

|`+MIGRATION_ABORTED+` |ERROR |The run stopped: connection failure or lost connection, target not empty or incomplete, storage unusable, heap too small. The detail names the cause. Fix it and run again (with `+--resume+` if rows were written).
